# Scene Review Card / Sahne kontrolü

## Türkçe

[Canlı aracı aç](https://omerbek.github.io/scene-review-card/).

Yazı hiyerarşisi, kontrast ve zamanlama için görsel inceleme kartı.

## Çalıştırma

`index.html` dosyasını bir tarayıcıda aç. Oynat düğmesini ve zaman çizelgesini kullanarak sekiz saniyelik sahneyi incele. HTML ve Canvas 2D ile çevrimdışı çalışır.


## Sahne ayarları

- İlk kontrol
- İkinci kontrol
- Üçüncü kontrol
- Onaylanan madde sayısı

Sekiz saniyelik zaman çizelgesinden bir kare seçip **PNG indir** ile 720 × 405 piksel dışa aktarabilirsin.

## English

Write three review checks and mark how many have passed.

Open [the live tool](https://omerbek.github.io/scene-review-card/) or open `index.html` in a browser. Switch between Turkish and English in the page header. Use the timeline to select a frame and **Download PNG** to save it at 720 × 405 pixels.
